# Relay

[![CI status](https://github.com/gfajula/relay/actions/workflows/ci.yml/badge.svg)](https://github.com/gfajula/relay/actions)

Self-hostable LLM gateway built with FastAPI: API keys, rate limits,
streaming, and usage/cost tracking. Work in progress. See PLAN.md.

## Quickstart

    docker compose up --build
    curl http://localhost:8000/healthz
